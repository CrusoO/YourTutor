# Changelog

All notable changes to YourTutor (Brownie) are recorded here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions follow the plan in [docs/ROADMAP.md](docs/ROADMAP.md) and [docs/RELEASES.md](docs/RELEASES.md).

## [Unreleased]

Code for v0.9 Safe Base (target 12 Nov 2026) merged in PR #30 on 5 Nov 2026 (distress detection and helplines, login fixes, the production start guard, guest syllabus scope; the same PR also carries the pitch video section). The v0.9 gate is not closed: the helplines are still marked `verified: false` (production will not start until they are verified), and key rotation is open. v0.95 Clean Base is in progress. A version ships only when its gate passes. See [docs/ROADMAP.md](docs/ROADMAP.md).

### Changed
- Student-facing labels no longer name any exam board or publisher (owner's decision, 2026-11-24). The practice-question label is now "Original Brownie practice question.", the pattern tag reads "Question type seen in board exam papers: ...", and the footer says Brownie is not affiliated with any exam board or textbook publisher and keeps only the link to the official papers (`apps/api/app/content/labels.py`, `apps/web/lib/independence.ts`, and the three tests that pin the text). Code comments and internal ids still say CBSE; students never see them.
- Page-weight budget raised from 150 KB to 152 KB (`apps/web/scripts/check-weight.mjs`, the CI step name, `docs/UI_STANDARDS.md`). The reviewer desk adds about 0.7 KB of CSS that every page downloads, which took the home page to 150.6 KB. Its own commit, so it is easy to revert.
- Refactor: the six status symbols (not started, learning, can do it, solid, review due, coming soon) were copied into both status chips; they now live once in `apps/web/lib/flow.ts` as `STATUS_MARK` and both chips import them (PR #112). Nothing on screen changes.
- Plan: the owner chose Easy-read (Atkinson Hyperlegible Next for Latin, Noto Sans Devanagari kept for Hindi and Nepali) as the interface font for UI-6; Clean (Geist) and Book (Source Serif 4) become learner choices. Plan and docs only; no font change in the app yet. Native readers still check the Latin and Devanagari pairing.

### Fixed
- Tests and a production start no longer hang when the database does not answer: database connections now have a 5 second connect timeout (`app/db/session.py`, `engine_options`). With Docker stopped, every test that starts the app waited forever on the startup schema check (PR #110).
- A test route leaked into the whole suite: `tests/hardening/test_operator_and_errors.py` added `/__boom` to the shared app and never removed it, so the API contract snapshot failed in some random test orders. The test now cleans up after itself and the snapshot never reads a cached spec (PR #111).
- Flaky test: `tests/doubt/test_route.py::test_logs_hold_a_hash_and_an_outcome_and_no_numbers` failed now and then because the random hex digest in the log line ("h=...") can contain the digits the test searches for ("613"). The test now ignores the digest before checking that no input numbers are logged. Test only; no app change.
- `app/tokens.css`: the comment on `--c-accent` said the white label reaches 6.6:1; the computed value is 5.18:1 (still above the 4.5:1 minimum). Comment only; no colour changed. `docs/UI_CONTRAST.md` was regenerated from the live test output because its old table had drifted.
